A compact chess engine in a single `main.py` (Python 3.13, standard library only).

Search: alpha-beta with quiescence, thinking up to 40,000 nodes a move.
The engine packs into 2,899 bytes, inside the 4,096-byte limit.

Run: `python3 main.py`
